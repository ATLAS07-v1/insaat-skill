# Mesaj Şablonları

## Müşteri Durum Güncellemesi

```markdown
Konu: [Proje] - [İş Paketi] Durum Güncellemesi - [Tarih]

Merhaba [Alıcı],

[Proje / iş paketi] kapsamında güncel durum aşağıdaki gibidir:

- Tamamlanan işler:
- Devam eden işler:
- Bekleyen kararlar:
- Riskler / dikkat edilmesi gereken konular:
- Beklenen aksiyon:
- Hedef tarih:

Ekler:
- [Ek listesi]

Bilgilerinize sunarız.
```

## Taşeron İş Talimatı

```markdown
Konu: [Proje] - [Mahalde] [İş Kalemi] Uygulama Talimatı

Merhaba [Taşeron Yetkilisi],

Aşağıdaki işin belirtilen kapsam ve referanslara göre planlanmasını rica ederiz:

- Lokasyon / mahal:
- İş kapsamı:
- Referans çizim / revizyon:
- Teknik şartname / method statement:
- Kalite ve İSG koşulları:
- Başlangıç / bitiş hedefi:
- Teslim edilecek kayıtlar:

Uygulamaya başlamadan önce eksik bilgi veya çakışma varsa yazılı olarak bildirmenizi rica ederiz.
```

## RFI Taslağı

```markdown
Konu: RFI-[No] - [Proje] - [Konu]

Merhaba [Alıcı],

Aşağıdaki konu için yazılı açıklama/onay talep ediyoruz:

- Referans:
- Saha / mahal:
- Soru:
- Mevcut durum:
- Karar gecikirse etkisi:
- Beklenen cevap tarihi:

Ekler:
- [Çizim/fotoğraf/model referansı]
```

## Submittal / Transmittal Notu

```markdown
Konu: Submittal-[No] / Transmittal - [Belge Grubu] - [Revizyon]

Merhaba [Alıcı],

Aşağıdaki belgeleri inceleme/onay için iletiyoruz:

| Belge | Revizyon | Tarih | Amaç | Not |
|---|---|---|---|---|

Beklenen aksiyon: [inceleme / onay / bilgi]
Beklenen dönüş tarihi: [tarih]
```

## Toplantı Tutanağı

```markdown
## Toplantı

- Proje:
- Tarih:
- Katılımcılar:
- Konu:

## Kararlar

| No | Karar | Sorumlu | Termin |
|---|---|---|---|

## Aksiyonlar

| No | Aksiyon | Sorumlu | Termin | Durum |
|---|---|---|---|---|

## Açık Konular

| No | Konu | Beklenen bilgi | Sorumlu | Termin |
|---|---|---|---|---|
```

## Kısa Saha Mesajı

```markdown
[Proje / mahal] için [iş kalemi] kapsamında bugün [aksiyon] gerekiyor.

Referans: [çizim / talimat / tutanak]
Termin: [tarih/saat]
Sorumlu: [kişi/ekip]
Eksik bilgi varsa başlamadan önce yazılı teyit rica ederiz.
```
